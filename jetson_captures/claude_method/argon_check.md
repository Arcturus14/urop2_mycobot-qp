$$\begin{pmatrix} X_{\text{bolt}} \\ Y_{\text{bolt}} \end{pmatrix} = \begin{pmatrix} S_X \\ S_Y \end{pmatrix} + \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix} \begin{pmatrix} 25w \\ -25u \end{pmatrix}$$

$$\begin{cases}
X_{\text{bolt}, k} = X_k + o_x \cos\psi_k + o_y \sin\psi_k = S_X + 25w_k\cos\theta + 25u_k\sin\theta \\
Y_{\text{bolt}, k} = Y_k + o_x \sin\psi_k - o_y \cos\psi_k = S_Y + 25w_k\sin\theta - 25u_k\cos\theta
\end{cases}$$

### 4.2 경우 1: 공구 오프셋을 넣지 않은 경우 ($(o_x, o_y) = (0, 0)$)

  $$S_Y = \bar{Y} - (\bar{p}_x\sin\theta + \bar{p}_y\cos\theta) = -73.500 - (-10.915) = \mathbf{-62.58\text{ mm}}$$

### 4.3 경우 2: 공구 오프셋 $(o_x, o_y)$을 미지수로 넣은 경우
#### (a) 실측 6개 전체 최소제곱 추정
중심화된 $\tilde{a}_k = a_k - \bar{a}$, $\tilde{b}_k = b_k - \bar{b}$에 대해 정규방정식 계수를 구하면:
- $A_0 = \sum_{k=1}^6 (\tilde{a}_k^2 + \tilde{b}_k^2) = 6 - 6(\bar{a}^2 + \bar{b}^2) = 6 - 4.15411 = \mathbf{1.84589}$

- $R_{ox} = -\sum (\tilde{a}_k X_k + \tilde{b}_k Y_k) = \mathbf{-146.684}$, $\quad R_{oy} = -\sum (\tilde{b}_k X_k - \tilde{a}_k Y_k) = \mathbf{+254.975}$

  $$C_1' = C_1 - \frac{M_{11}R_{ox} + M_{12}R_{oy}}{A_0} = 74150.42 - 48013.12 = \mathbf{26137.30}$$
  $$C_2' = C_2 - \frac{M_{12}R_{ox} - M_{11}R_{oy}}{A_0} = -2932.92 - (-1566.17) = \mathbf{-1366.75}$$

  $$o_y = \frac{254.975 - 266.059\cos\theta - 141.722\sin\theta}{1.84589} = \mathbf{-1.80\text{ mm}}\quad (\|\mathbf{o}\| = 5.06\text{ mm})$$
